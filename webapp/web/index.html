What you get back

Airway mask3D, fused
Branch labelslobe and segment
Centrelinebranch tree
Confidenceper voxel and branch
MeasurementsALR, percentiles for age
ITK-SNAP bundlefor correction

All files are NIfTI in the orientation of the uploaded scan, with an in-browser 3D view. Files are kept on the server only as long as needed to serve them.

Method: union of AirMorph-R, MEDPSeg-R and TfeNet; the component overlapping AirMorph-R is kept (anchored selection); branches are named by a graph transformer. Confidence is calibrated on the ATM'26 validation set.
